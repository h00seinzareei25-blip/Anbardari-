# FocusFlow 🎯 — اپ ضد تنبلی

> **هدف**: کمک به تبدیل شدن به آدمی پیگیر و منضبط

## ویژگی‌های اپ

### ✅ مدیریت وظایف
- افزودن کار با عنوان، توضیحات، اولویت (بالا/متوسط/کم)
- دسته‌بندی: کار، شخصی، سلامت، یادگیری، سایر
- تخمین تعداد پومودورو برای هر کار
- علامت‌گذاری کارهای انجام‌شده
- سیستم امتیاز برای هر کار تمام‌شده

### 🍅 تایمر پومودورو
- تایمر ۲۵ دقیقه‌ای با انیمیشن دایره‌ای
- استراحت کوتاه ۵ دقیقه‌ای بعد از هر سشن
- استراحت طولانی ۱۵ دقیقه‌ای بعد از ۴ سشن
- اتصال به کارها (شمارش پومودورو برای هر کار)
- پیام‌های انگیزشی تصادفی

### 🔥 سیستم Streak
- ردیابی روزهای متوالی فعالیت
- نمایش بیشترین streak داشته‌شده
- اعلان هشدار در صورت خطر شکستن streak

### 📊 آمار و پیشرفت
- نمودار فعالیت ۳۰ روز گذشته (heatmap)
- سیستم سطح‌بندی با ۸ مرحله (از تازه‌کار تا افسانه‌ای)
- تعداد کل کارها و پومودوروهای انجام‌شده
- امتیاز کل

### 🔔 اعلان‌های هوشمند
- یادآوری هر ۴ ساعت اگر کار باقی‌مانده داری
- اعلان ساعت ۸ شب برای حفظ streak

## نصب و راه‌اندازی

### پیش‌نیازها
- Android Studio Hedgehog یا جدیدتر
- Android SDK 26+
- Java 17

### مراحل
```bash
git clone <repo-url>
cd FocusFlow
```
سپس پروژه را در Android Studio باز کن و Run کن.

## معماری
- **MVVM** با Jetpack ViewModel
- **Room** برای دیتابیس محلی
- **Hilt** برای Dependency Injection
- **WorkManager** برای اعلان‌های زمان‌بندی‌شده
- **Jetpack Compose** برای UI
- **Material Design 3** با تم تاریک
